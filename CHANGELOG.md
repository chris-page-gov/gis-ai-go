# Changelog

All notable changes to GIS AI GO are recorded in this file. The project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Material pull requests add a fragment under [`changelog.d/`](changelog.d/README.md).
The release pull request folds those fragments into this file, synchronises all
version fields and removes the consumed fragments.

## [Unreleased]

### Added

- Stage 0 repository, research provenance, governance, candidate contracts,
  synthetic fixtures, architecture sources and assurance harness.
- MIT licensing for the project-authored repository and preserved research pack.
- Live context, progress, implementation roadmap and issue-backed delivery model.

### Changed

- Superseded the research codename with **GIS AI GO**.
- Progression is now controlled by evidence gates and pull requests rather than a
  local Stage 0 pause.
