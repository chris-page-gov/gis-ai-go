# Three-pane local geography experience

The interface helps someone choose a question, inspect its evidence and explain its limits. It uses a task navigator, one active workspace and a reference inspector. Tasks group activities and concepts; they are not Docker containers, storage directories or newly acquired datasets.

This is a presentation design. The private demonstration has a separate, unchanged source model. These public-safe design assets contain no selected feature data, account observations, credentials or local evidence paths. They establish no deployment, provider entitlement or full-coverage claim.

## Guidance and design basis

The design follows the existing [EXPERIENCE-221 learning and evaluation contract](https://github.com/chris-page-gov/gis-ai-go/blob/main/docs/implementation/EXPERIENCE-221_LEARNING_AND_EVALUATION.md), [authored persona catalogue](https://github.com/chris-page-gov/gis-ai-go/blob/main/evaluation/experience/catalogue.v1.json) and [geography explanation guide](https://github.com/chris-page-gov/gis-ai-go/blob/main/docs/implementation/GEOGRAPHY_DATES_AND_CLASSIFICATIONS.md). The reviewed Explorer learning-presentation pattern supplies goal → activity → observable outcome → safeguard → source. It is an authored learning overlay, not a new geographic assertion.

## Information architecture

1. Start with a question: choose one of five learning stages and an authored role perspective. Show one activity at a time, with previous/next controls.
2. Explore statistical areas: select a geography and follow published membership.
3. Compare lookup groupings: inspect administration and classifications, with a chart and complete table alternative.
4. Follow identifier links: use typed, source-owned relationships before unnecessary spatial work; retain unobserved targets and representation limits.
5. Compare settlements: preserve dated BUA assignments, native discrepancies and the not-covered category.
6. Inspect code dates: compare recorded instances without inferring polygon validity or succession.
7. Check methods and limits: keep original caveats, source links, historical notes and proposal previews accessible.

A local authority is an organisation. Its administrative geography is a different entity. Statistical areas, administrative geographies, settlements and native features are not one universal containment hierarchy. Lookup membership and identifier associations are labelled by their source method and edition.

## Reference inspector

Task help follows the active task until pinned. Pinning retains the selected reference tab and search query; users can explicitly choose another tab. The glossary shows authored source-linked definitions, scope, attributed search variants and explicitly labelled source-only guidance. An alias is a retrieval aid, not an exact-match assertion or a quantity. A separate date tab distinguishes reference period, boundary edition, product release, retrieval and code validity.

Native buttons support Enter and Space. Reference tabs support Left/Right/Home/End, keep one tab stop and label their panels. Escape folds a side pane and returns focus to its reopening control. Narrow screens use stacked, bounded panels; complex tables may scroll locally. The integration must not create a keyboard trap or make essential explanations hover-only.

## Learning and authored coverage

The companion persona/story matrix declares seven role personas and 26 interface capabilities. Assistive technology, language and expertise are cross-cutting needs, not a single persona or a ranking of users. Each capability has a story, visible outcome, source basis, JIT concept and learning stage. This measures authored coverage only. Human comprehension, task completion, screen-reader and Voice outcomes remain untested.

Practice ticks remain in memory and clear on reload. They are neither assessment nor certification. The interface does not record a conversation, submit work or change account access.

## Acceptance and preservation

- The model is byte-for-byte unchanged. All existing data controls, native fields, null/absence meanings, source diagnostics and dates remain reachable.
- Only one task workspace is visible. Switching task does not execute a provider call, invent a join or mutate the source model.
- Identifier-first associations, explicit missing targets and separate versions remain inspectable. Drawing a feature does not establish access, topology or containment.
- Complete selected BUA rings and native attributes remain available; the pseudo-code has no invented geometry or rurality meaning.
- Focus, pinned-reference state, narrow layouts, local history, search and empty states receive meaningful automated checks. Manual assistive-technology and human evaluation are separately reported.
- The server serves a fixed set of checksum-verified local files on loopback. Definitions are embedded locally; external sources open only following a deliberate link selection.

## Publication boundary

Only this specification, the authored matrix, presentation overlay/CSS and the separately reviewed public vocabulary projection are candidates for publication. The private model, private screenshots, local server receipts and scenario results containing selected-data counts are excluded. Repository assurance and editorial review remain the publication gate.
