# NHS Postcode Directory for the UK Full (February 2021)

This file contains the 'Full' NHS Postcode Directory (NHSPD) as at February 2021. The NHSPD relates both current and terminated postcodes in the United Kingdom to a range of current statutory administrative, electoral, health and other geographies. It also links postcodes to pre-2002 health areas and both 2001 Census and 2011 Census Output Areas and Super Output Areas. The NHSPD is issued quarterly. For further technical information about this file, please refer to the User Guide contained within the downloadable zip file. Please note that this product contains Royal Mail, Gridlink, LPS (Northern Ireland), Ordnance Survey and ONS Intellectual Property Rights. (File Size - 107 MB)
