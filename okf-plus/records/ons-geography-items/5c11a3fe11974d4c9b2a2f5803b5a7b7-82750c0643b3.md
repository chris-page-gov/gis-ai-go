# GB

This file contains the digital vector boundaries for countries in Great Britain as at December 2011. The top-level division of administrative geography in the United Kingdom is the four countries - England, Wales, Scotland and Northern Ireland. This file only contains information for Great Britain. This product contains both the nine character codes as well as the old style three character codes. For further information, please see the Code History Database (CHD) (Link below). The boundaries are Intermediate/Generalised (20m). Intermediate datasets are designed for high quality mapping, preserving much of the original detail from the full dataset, but typically 10% of the file size. They are great when used in conjunction with the OS raster products and for producing detailed regional and local maps, or large wall maps. They are also suitable for non-demanding GIS analyses (such as buffering). Intermediate datasets are a good compromise between detail and small file size. They have also been clipped to the clipped to the coastline (Mean High Water mark), giving the coastline a more orthodox appearance. Please note that this product contains both Ordnance Survey and ONS Intellectual Property Rights.
