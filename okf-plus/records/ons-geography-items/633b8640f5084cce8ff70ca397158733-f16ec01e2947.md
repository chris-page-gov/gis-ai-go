# Built Up Areas (December 2024) Boundaries EW BGG (V2)

This file contains the digital vector boundaries for built up areas in England and Wales as at 2024. The built up area boundaries are generalised and created using an automated approach based on a 25m grid squares (BGG). Only the latest versions of the products are available on the OS DataHub whereas we have the 2011 built-up areas, 2022 built up areas and these ones. This file has been created from OS Open Built Up Areas . Further information about this product can be found in our FAQ document or from Ordnance Survey’s OS Open Built Up Areas | Data Products | OS . Built Up Areas (December 2024) Boundaries EW BGG (V2) has a naming edit to the BUA code E63009256, the English name is corrected to Oswestry and Welsh name to Croesoswallt. Please note that this product contains both Ordnance Survey and ONS Intellectual Property Rights.
