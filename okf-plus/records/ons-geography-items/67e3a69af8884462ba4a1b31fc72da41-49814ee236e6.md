# Enumeration Districts (1991) Boundaries EW

This file contains the digital vector boundaries for the Enumeration Districts in England and Wales as at 1981. Contains both Ordnance Survey and ONS Intellectual Property Rights. This 1991 Census Enumeration District (ED) boundary set – developed from the 1990s boundary set produced by the ED-line consortium – resolves long-standing issues with versions available elsewhere. Previously unaddressed problems included small-population EDs that were formed into amalgamated areas which previously could not be mapped correctly, the impacts of boundary-change Statutory Instruments taking effect before the 1991 Census Day, and various inaccuracies around the coast. The ED polygons can be matched to the ED-level SAS data available at NOMIS ( https://www.nomisweb.co.uk/datasets/sas91 ) using the field ‘NOMIS_code’.
