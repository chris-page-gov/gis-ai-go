# LHB_2013_WA_BSC

This file contains the digital vector boundaries for local health boards in Wales as at December 2013. The local health boards (LHBs) in Wales were reorganised on 1st October 2009. There are now seven LHBs which are responsible for local health administration in Wales. LHBs are groups of one or more unitary authorities. This product contains both the nine character codes as well as the old style three character codes. For further information, please see the Code History Database (CHD) (Link below). Super generalised boundaries are designed for national mapping where high levels of detail are not required. They have very small file sizes which also makes them suitable for mapping on the web. They should not be used for GIS analyses. They have also been clipped to the coastline (Mean High Water mark), giving the coastline a more orthodox appearance. Please note that this product contains both Ordnance Survey and ONS Intellectual Property Rights.
