# NHSCR_2013_EN_BSC

This file contains the digital vector boundaries for NHS commissioning regions in England as at April 2013. There are four NHS commissioning regions in England. This file contains the nine character coding only. For more information, please see the Code History Database (CHD) (link below). Super generalised boundaries are designed for national mapping where high levels of detail are not required. They have very small file sizes which also makes them suitable for mapping on the web. They should not be used for GIS analyses. They have also been clipped to the coastline (Mean High Water mark), giving the coastline a more orthodox appearance. Please note that this product contains both Ordnance Survey and ONS Intellectual Property Rights.
