# BaseMap OS VectorMap Local 'Carto' Resampled

The OS VML 'Carto' Base Map (Resampled) is designed to be used as background mapping providing a seamless map view from small to large scales with a consistent cartographic representation. The sources of data are Ordnance Survey Strategi data for small and mid-scales, Vector Map District and Vector Map Local for largest scales. This service includes an additional zoom scale for OSMM data which is resampled at the largest scale to allow the map to be viewed at 1:625. The currency of the data is; Strategi - 01/2016 Vector Map District - 09/2015 Vector Map Local - 01/2016 The coverage of the map service is GB. The map projection is British National Grid. The service is appropriate for viewing down to a scale of 1:625 Updated: 29/01/2016
