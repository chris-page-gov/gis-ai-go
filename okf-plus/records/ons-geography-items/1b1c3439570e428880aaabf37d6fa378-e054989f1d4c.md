# NHS England (Region) (April 2017) Names and Codes in EN

This file contains the NHS England (Region) (NHSER) names and codes, as at 1 April 2017 in England. This file replaces the NHS Commissioning Region (April 2017) Names and Codes in England file. Organisation Data Service, part of NHS Digital, received formal confirmation from NHS England that they wished to update the collective organisation role/type names for the NHS Commissioning Regions. The new name for these geography entities are NHS England (Region). This is purely a change to organisation role names. The associated organisation role codes, and the names and codes of individual organisations of this type, will all remain unchanged.
