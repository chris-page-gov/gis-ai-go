# Preferred label

A selected lexical label for a concept in a specified language.

Project display labels and source-authoritative labels must have separate provenance; unknown language stays unknown.

Definitions are project paraphrases. Native forms, source abbreviations and project search variants retain separate authority. No equivalence is inferred.
