# Web Ontology Language

A language for expressing formal classes, properties, individuals and logical relationships.

OWL identity or class-equivalence assertions are stronger than navigation and should not be generated from label similarity.

Definitions are project paraphrases. Native forms, source abbreviations and project search variants retain separate authority. No equivalence is inferred.
