# Connecting Link v1

The Road and Path Networks are not topologically structured together. Connecting Links have been introduced to enable a connection between the Road Network and the Path Network without splitting the Road Network. A Connecting Link feature is a linear spatial object which represents a logical connection between the Path Network and the Road Network, and they do represent a feature in the real world. A Connecting Link will always reference a Path Node and a Connecting Node.
