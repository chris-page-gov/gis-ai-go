# OKF+ third-party material

## OKF+ metadata and context dependencies

This module contains normalised factual OS, ONS and Nomis
metadata, with per-record source references and separate metadata/data rights.
Source identifiers, titles, schema fields and attribution are preserved. The
repository's software licence does not replace provider terms or license
protected data. Original acquisition responses remain in ignored local evidence;
no OS licensed feature payload or statistical observation download is published.

The minimal Explorer context dependency is pinned to commit
`84fb37f11411c04db8c58046827061f741249002` in
[`okf-plus/vendor/explorer-context`](vendor/explorer-context/manifest.json).
Its manifest records exact upstream paths, source revision, byte counts and
SHA-256 digests. Upstream licence notices accompany the five engine files and
eight schemas. The offline producer verifies the manifest and every vendored
file before use. This reuse does not imply upstream acceptance of OKF+ or
registration with installed Ask OKF.
