# GIS AI GO v0.1.0

Released on 20 August 2026.

## What this release provides

GIS AI GO `v0.1.0` is the first supported public discovery release. It provides:

- an accessible static Explorer at <https://chris-page-gov.github.io/gis-ai-go/>;
- a deterministic 36-record public OKF bundle: 1 bundle, 3 dataset records, 4
  provider descriptions, 24 source records and 4 non-executing workflows covering
  reviewed HM Land Registry, ONS and LandIS evidence;
- catalogue search, facets, governed record cards, graph, timeline and non-legal
  coverage-schematic views;
- linked Markdown, JSON and JSON-LD projections with source, authority, access,
  rights and freshness evidence; and
- checksummed, provenance-attested GitHub Pages artefacts with verified deployment,
  rollback and restoration paths.

## Assurance

The release gate includes locked type, unit, contract and real-browser tests;
byte-identical repeated clean builds; source, schema, checksum, rights and link
validation; a CycloneDX SBOM; CodeQL; baseline secret scanning; keyboard, reflow,
forced-colours and reduced-motion journeys; and automated WCAG A/AA checks.

The checksummed release assets and public-verification receipt bind the supported
deployment to its exact source commit, archive digest, payload root, OKF content
root and public checksum ledger.

GitHub Pages creates its supported transport envelope from the already verified
logical payload. That platform envelope is not represented as the immutable source
archive retained with the release.

## Important boundaries

- This release is a static metadata discovery product. It does not provide an MCP
  service, provider execution, identity integration, policy engine, protected-data
  integration or transactional evidence store.
- The product is not endorsed by HM Land Registry, Ordnance Survey, ONS or LandIS.
  Provider records describe bounded metadata evidence and do not relicense source
  data.
- HMLR INSPIRE polygons are indicative and do not establish the exact legal extent
  of a title. The Explorer's coverage schematic is not a title, property or parcel
  map.
- Source currency, access and reuse remain record- and provider-specific. Follow
  the evidence and official terms displayed for each record.
- The project-local OKF publication and profile remain candidate contracts. Product
  support does not make the profile a final external standard or imply that every
  described source is open or operationally supported.
- Automated accessibility tests are regression evidence, not a specialist audit or
  user research with disabled people. Security automation is a baseline, not a
  penetration test of future executable services.
- GitHub Pages provides the hosting boundary. The application enforces its exact
  meta Content Security Policy but cannot set every response header itself.
