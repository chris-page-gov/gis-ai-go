# Architecture diagrams

The [implemented architecture](../docs/architecture/README.md) documents the reviewed
source with Mermaid component, sequence and state diagrams, formal invariants,
contracts and immutable Git line links. Its [review](../docs/architecture/REVIEW.md)
records dead-code candidates and refactoring recommendations separately from the
existing historical and operational diagram sources below.

`source/dot/` and `source/mermaid/` are candidate operational copies promoted from the
research pack. CI renders the DOT sources into `artifacts/diagrams/`; generated output
is not committed. The original generated SVGs remain unchanged in the research pack.
