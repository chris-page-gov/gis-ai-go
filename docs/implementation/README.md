# Implementation

These are the live delivery documents for GIS AI GO. They supersede planning text
inside the immutable research pack without rewriting that evidence.

- [`ROADMAP.md`](ROADMAP.md) defines release outcomes and evidence gates.
- [`BACKLOG.md`](BACKLOG.md) maps stable work-item identifiers to release scope.
- [`DELIVERY_AND_RELEASE.md`](DELIVERY_AND_RELEASE.md) defines the branch, pull
  request, version, release, deployment and rollback workflow.

Current task status belongs in [`PROGRESS.md`](../../PROGRESS.md). Historical change
belongs in [`CHANGELOG.md`](../../CHANGELOG.md). Once GitHub issues exist, they are
the source of truth for item-level state.
