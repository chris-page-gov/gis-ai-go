# How to read and verify the evidence

The product baseline is commit `6c76c92a18da779766f8d49acbbd7dbbd31abb97`.
The chronology uses Git committer timestamps converted to Europe/London with the
UTC offset retained. They establish order and recording time, not working duration.
Pull-request creation, merge and check times are different events.

The public commit ledger is generated from that exact Git history. Its rows include
the commit, timestamp, subject and public source URL. The public claim index states
the evidence for each main narrative claim and its limitation. A generated
SHA-256 manifest binds the report's input and output files. This is a local
content manifest, not a GitHub provenance attestation or release acceptance.

## Primary, derived and missing

- A primary record is a retained observation, code revision, tool event, review or
  check result. Its existence alone does not establish the author's interpretation.
- A derived fact is computed from named primary records, such as a distinct agent
  count after duplicate generations are removed.
- An interpretation explains a relationship. It must state uncertainty and plausible
  alternatives where the evidence does not establish cause.
- A recommendation describes future action and has no claim to be implemented.
- An unavailable record is a gap. It is not a zero, a success or an opportunity to
  invent an estimate.

## Private and public products

The private working record retains source identifiers and the detailed crosswalk
to preserved projections. The public record uses independently reviewed public
references and specifically cleared aggregates. It does not contain raw private
prompts, account details, authentication, machine paths, session identifiers,
provider billing or hidden model reasoning.

For every candidate source, record one disposition: public exact source, approved
excerpt, paraphrase/aggregate, withheld or unavailable. Do not infer redistribution
rights from local access. The non-redistributable AI research PDF remains ignored.
The preserved internal reasoning exclusions remain in force; the narrative uses
decisions expressed in messages, reviews, commits and documents.

Public claims can be audited through their public sources, but the redacted public
edition cannot independently prove completeness of the private conversation corpus.
The private source index explains that limitation without exporting its contents.

## Counting work

Count unique agent identities separately from task assignments, resumed turns,
spawn events and worker processes. A UI total is a lead to investigate; it does
not establish simultaneous concurrency. Follow-up work can reuse an existing
agent. The model writes a task request and calls a host facility; the host creates
the execution context and enforces its permissions and resource limits.

Count Claude observations separately from code patches, verification reruns and
authentication attempts. Deduplicate copied event generations before totalling.
Retain failed, aborted and unscored observations. Anchor the first attempt and the
accepted final result where primary records permit it.

Separate elapsed time, active model/tool execution, CI wait, authorisation or
authentication wait, machine unavailability and operator time. Concurrent work
must not be summed as elapsed duration. Token totals, subscription allowance and
provider charges are different units. Do not price historical work using a current
API price or allocate an entire subscription charge to one task without evidence.

## The model-transition evaluation

For future comparable tasks record model and host setting, guidance revision,
task type, accepted outcome, iterations, repeated checks, wall time and measured
usage if available. Compare tasks matched by scope. Change one factor at a time
where practical. Report samples and uncertainty; increased capability is a reason
to test an approach, not a result of that test.

## Publication and updates

An editorial update receives its own date and content manifest. It does not move
the baseline or rewrite historical evidence. Review secret/PII handling, source
rights, links, diagram legibility, PDF pagination and assertions before publication.
The A4 PDF is a print companion; the HTML/Markdown reader retains navigable sources
and searchable tables. A PDF generated by this workflow is not asserted to be
PDF/UA conformant.
