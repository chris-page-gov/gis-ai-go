# ADR-0002: GIS AI GO project name

- status: accepted working identity
- decided on: 19 August 2026
- decision maker: human repository owner
- supersedes: research decision D20, “Locus Accord”

## Decision

Use **GIS AI GO** as the product name and `gis-ai-go` as the repository and package
slug. Use `io.github.chris-page-gov/gis-ai-go` as the provisional MCP Registry
identifier if a server is later published.

The mnemonic is “give us AI governed output”. It is wordplay, not a formal acronym
or a claim that AI governs the result. The formal descriptor is **governed geospatial
knowledge and action for people, systems and AI agents**.

## Evidence and limits

A point-in-time screen on 19 August 2026 found no exact GitHub repository, official
MCP Registry entry, npm package or PyPI distribution using `gis-ai-go`. The queries,
results and limits are recorded in the
[name-screening evidence](../source-ledger/name-screening-2026-08-19.md).
Availability is not a reservation or trade mark clearance.

Keep spaces in the display name and hyphens in technical names. Do not compress the
identity to `GISAI` or `gisaigo`, which have adjacent existing uses and are harder to
parse.

## Consequences

Operational copies use GIS AI GO identifiers. Historical reports, manifests and
checksums retain the superseded codename so that research provenance remains intact.
