Stage 0, not as blanket authority for later production stages. Research decision D20
is superseded by ADR-0002.

ADR-0004 supersedes only the Stage 0 pause and remote-publication restrictions in
ADR-0001 and ADR-0003. Their repository, provenance, licensing and safety decisions
remain in force.
