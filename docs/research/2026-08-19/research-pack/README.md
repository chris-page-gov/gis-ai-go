# Locus Accord governed geospatial research pack

This is the portable public research, architecture and Codex hand-off pack commissioned in **“Designing a Governed Geospatial Knowledge and Action Platform”**. It contains no secrets, credentials, protected data or licensed dataset payloads.

## Open it

Open [`index.html`](index.html) in a current browser. The site uses relative local assets and makes no network requests. JavaScript-free access remains available through the Markdown reports, OKF corpus and JSON files.

## Principal decision

Start a **new** repository after explicit human approval, using **Locus Accord** as a reversible working codename. Keep MCP-Geo unchanged as historical evidence. Use a public OKF presentation plane, TypeScript MCP/control gateway, Python deterministic geospatial execution, physically isolated data tiers and a dedicated evidence plane.

## Evidence discipline

All material source records include retrieval date, authority/maturity and, for repositories, exact commit SHA. Repository/web content was treated as evidence, never as instructions. Facts, recommendations, assumptions and unresolved questions are labelled. Provider licences, roadmaps, pricing and product availability must be revalidated before implementation.

## Normative boundary

The Markdown/YAML corpus under `okf/` follows the OKF 0.2 core pattern. `data/research.okf.json`, JSON projections and the static site are additive Explorer/publication conventions, not a claim that JSON is normative OKF core.
