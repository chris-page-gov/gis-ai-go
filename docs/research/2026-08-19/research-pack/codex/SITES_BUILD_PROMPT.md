# Prompt for an optional open ChatGPT Sites build

Create a public, accessible, read-only site from this research pack. Use only the checked-in public JSON, Markdown, SVG and synthetic examples. Preserve relative-source links and source identifiers. Provide search, facets, decision comparison, provider/hosting matrices, graph, timeline, map and selected-item data cards. Meet WCAG 2.2 AA, work without account-specific protected data and expose no secret, provider credential, licensed feature payload or privileged operation. Optional WebMCP tools may search, facet, inspect, retrieve relationships/current-view evidence and export selected public metadata only. The canonical artefact remains the portable static pack; do not make Sites the source of truth. Show a visible banner that this is research, not an implemented or government-endorsed service. Record the Sites product version, region/account availability, deployment date and exported source/exit path.
