# Accessibility-test boundary

The supported public Explorer and experimental WebMCP Explorer have browser
accessibility checks in their respective application test directories. These cover
keyboard journeys, reflow and other supported display preferences alongside their
functional checks. See the [public Explorer](../../apps/public-explorer/README.md)
and [WebMCP Explorer](../../apps/webmcp-explorer/README.md) for commands and scope.

WCAG 2.2 AA acceptance remains a publication requirement. Automated checks provide
specific evidence; they do not alone establish complete accessibility conformance.
